# kbSensors
- Tiny monitor station for one DHT11, one CCS811 and many DS18B20 sensors for ESP8266 board
- Outputs data at http://kbsensors/ (optional ?refresh=&lt;seconds&gt;), http://kbsensors/xml , http://kbsensors/txt , http://kbsensors/json. (https is not available for now.)
- Sends data to MQTT
- Can get temperature & humidity from local sensors or another kbSensors instance or MQTT for CCS811 compensation

## INSTALLATION:
- The static files from `data/` are also embedded in the firmware (`assets.h`, generated by `python3 embed_assets.py` - run it after editing `data/*`), so the UI works without uploading them. Files uploaded to LittleFS take precedence.
- Use [this tool](https://github.com/earlephilhower/arduino-esp8266littlefs-plugin) for Arduino IDE to flash static files onto the ESP (or try `REMOTE_HELPER_SERVER` instead)
- Copy `secrets.h.example` to `secrets.h` and set `OTA_PASSWORD` (the file is ignored by git). Without it OTA updates stay disabled.
- First time: login to wifi kbSensors-xxxx, go to 192.168.4.1 and set the wifi network ssid+pass (kbSensors doesn't work as an AP except for the setup mode).

## SECURITY NOTES
- The settings pages (`/wifi`, `/mqtt`) use HTTP Basic auth; the default `admin` password has to be changed on first setup (or with the `webpass` serial command). Passwords are never sent back to the browser.
- `/reboot`, `/rescan` and `/edit` (sensor names/compensation) need the login too, unless you tick "Allow sensor edit without password" on the `/wifi` page (only do that in a trusted LAN).
- The configuration files (`wifi.json`, `config.json`, `mqtt.json`) are not served over HTTP.
- Serial console (115200 baud): `help` lists the commands (`ip`, `ssid`, `wifipass`, `wifi`, `webpass`, `reboot`...).
